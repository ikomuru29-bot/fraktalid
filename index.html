Best Practical Method

  1. Type the island name and let the app search OpenStreetMap.
  2. If a polygon is returned, the app measures that outline directly in kilometers.
  3. Use a smaller step size to follow more bends and a larger one for a coarser estimate.
  4. If no polygon is available, the best fallback is a satellite map plus manual tracing.

Why does the measured length increase?

Coastlines have structure at many scales. A large ruler skips smaller coves and jagged edges, so the measured length is shorter. A small ruler follows more of that detail, so the measured coastline gets longer.

Why this is easier

No manual scale entry: the geometry is in real coordinates already, so the result can be measured in kilometers directly.

No low-quality screenshot problem: when a polygon is available, we use vector geometry from map data instead of guessing from blurry pixels.

Mostly one input: usually you only need to type the island name and adjust the step-size slider.

More honest output: the app now shows both the measured coastline at your chosen ruler size and the full polygon perimeter from the loaded map geometry.

Visible ruler effect: the red outline on the map is the sampled measurement path, so it changes when you change the step size.

Important limitation: the coastline drawn by the basemap tiles when you zoom is not what gets measured. The measurement uses the loaded place geometry from OpenStreetMap/Nominatim.

Search for an island to load its outline. The app will show both the coastline estimate at your chosen ruler size and the full loaded polygon perimeter, so you can tell whether the slider or the source geometry is the limiting factor.
If you expect Saaremaa to be around 874 km and this still comes out lower even at a very small step size, that means the loaded OpenStreetMap polygon is more simplified than the coastline source behind that 874 km figure.
